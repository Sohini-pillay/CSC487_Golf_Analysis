# CSC487_Golf_Analysis
CSC 487 Final Project: Golf Swing Sequencing

Data Setup:
download the golf swing videos at this link: https://drive.google.com/file/d/1uBwRxFxW04EqG87VCoX3l6vXeV5T5JYJ/view
unzip file --> should result in folder "videos_160"
after installing appropriate dependencies (can use requirements.txt) run python extract_frames.py
folder names in vid_frames folder correspond to video id in key_frames.csv, the last digits correspond to the frame number, these match the particular key point in the event index column of key_frames.csv
